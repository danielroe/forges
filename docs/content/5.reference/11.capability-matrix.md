The matrix lists every capability for every provider, so you can compare forges next to each other and decide which ones your tool can support. Two columns make an assumption about how the provider is set up. The GitHub column assumes that you authenticate as an app with an installation, because with a token, `installations` isn't available. The Tangled column assumes that `notificationsUrl` is set.

To learn what each level of support means, see [Capabilities](/concepts/capabilities). Hover over a cell to see which verbs it covers, or open the [page of a provider](/providers) to read about one forge in detail.
