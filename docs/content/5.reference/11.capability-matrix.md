The matrix lists every capability for every provider, so you can compare forges next to each other and decide which ones your tool can support. Two columns make an assumption about how the provider is set up. The GitHub column assumes that you authenticate as an app with an installation, because with a token, `installations` isn't available. The Tangled column assumes that `notificationsUrl` is set.

To learn what each level of support means, see [Capabilities](/concepts/capabilities). Hover over a cell to see which verbs it covers, or open the [page of a provider](/providers) to read about one forge in detail.

- GitHub `classic` (Classic token): A personal access token (classic) or an OAuth app token
- GitHub `fine-grained` (Fine-grained token): A fine-grained personal access token or a GitHub App user access token
- GitHub `installation` (App installation): An app with an `installationId`, or an installation access token such as the `GITHUB_TOKEN` of a workflow
- GitHub `app` (App): An app without an `installationId`
- Cursor Origin `token` (User token): A user access token, as the Origin CLI reads from `CURSOR_AUTH_TOKEN`
- Cursor Origin `installation` (App installation): An app with an `installationId`
- Cursor Origin `app` (App): An app without an `installationId`
