title: Wire codec
description: Encode and decode the dates and bytes in forges models when they cross JSON.

JSON has no `Date` or `Uint8Array`. `forges` returns both in its model values, so anything that stores them or sends them over HTTP must encode them first.

Most code does not need this. Providers already return real `Date` and `Uint8Array` values. Use `forges/wire` only when model values cross a JSON boundary, such as storage, a worker, or a proxy.

`forges/wire` exports `encode()` and `decode()` for that boundary.

```ts
import { decode, encode } from 'forges/wire'

const wire = encode(result)
const value = decode(JSON.parse(JSON.stringify(wire)))
```

## Tags

`encode()` replaces values that JSON cannot represent:

- `Date` becomes `{ "$date": "<ISO 8601>" }`.
- `Uint8Array` becomes `{ "$bytes": "<base64>" }`.

Everything else is copied unchanged.

`decode()` is strict: a malformed `$date` or `$bytes` tag throws a `TypeError`.
