---
title: JSON Schemas
description: Validate stored events, or generate types in another language.
icon: i-lucide-file-json
---

`forges/schema` exports a JSON Schema for each public model type, keyed by type name. References use OpenAPI's `#/components/schemas/<Type>` form:

```ts
import { schemas } from 'forges/schema'

// { type: 'object', properties: { ref: ..., kind: ... } }
schemas.Thread
```

`forges/schema/<Type>.json` serves each schema as a standalone draft-07 document. Use them to validate stored events or to generate types in another language.
