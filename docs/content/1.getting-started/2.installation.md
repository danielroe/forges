Install the package from npm:

::code-group
  ```sh [pnpm]
  pnpm add forges
  ```
  ```sh [npm]
  npm install forges
  ```
  ```sh [yarn]
  yarn add forges
  ```
  ```sh [bun]
  bun add forges
  ```
::

`forges` requires Node.js 22.18 or later. The package is ESM only and ships its own types. It has no runtime dependencies and uses the global `fetch`. To use another implementation, pass a `fetch` option to a provider.

## Import paths

The root entry exports every provider and the shared helpers:

```ts
import { createForges, github } from 'forges'
```

Each provider also has its own subpath. A bundle that imports one subpath contains one forge:

```ts
import { github } from 'forges/github'
```

| Subpath | Contents |
| --- | --- |
| `forges/github`, `forges/gitlab` and so on | One provider. See [Providers](/providers) |
| `forges/env` | [Configure providers from the environment](/guides/environment) |
| `forges/fake` | An in-memory forge for [tests](/guides/testing) |
| `forges/testing` | Fixture replay and webhook signing for [tests](/guides/testing) |
| `forges/schema` | [JSON Schemas](/reference/json-schemas) for the model types |

## Browsers

Every provider except pushin.eu has a Lite factory, such as `githubLite()`, that leaves out webhook code. Use it in browser code. Read [Browser bundles](/guides/bundling) for sizes and details.
