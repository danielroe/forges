You can install `forges` from npm with the package manager of your choice:

::code-group
  ```sh [pnpm]
  pnpm add forges
  ```
  ```sh [npm]
  npm install forges
  ```
  ```sh [yarn]
  yarn add forges
  ```
  ```sh [bun]
  bun add forges
  ```
::

The package requires Node.js 22.18 or later. It is ESM only and ships its own types, so you don't need to install anything extra for TypeScript. `forges` has no runtime dependencies and sends its requests with the global `fetch`. If you want to use a different implementation, for example in a test or on a runtime that has no global `fetch`, pass it to a provider with the `fetch` option.

## Import paths

The root entry exports every provider along with the shared helpers, so a single import is enough to get started:

```ts
import { createForges, github } from 'forges'
```

Each provider also has a subpath of its own. Bundlers drop the providers you don't use when you import from the root, but a subpath import is more explicit, because it names the one forge you depend on:

```ts
import { github } from 'forges/github'
```

Besides the providers, the package has a few more subpaths for specific jobs:

| Subpath | Contents |
| --- | --- |
| `forges/github`, `forges/gitlab` and so on | One provider. See [Providers](/providers) |
| `forges/env` | [Configure providers from the environment](/guides/environment) |
| `forges/fake` | An in-memory forge for [tests](/guides/testing) |
| `forges/testing` | Fixture replay and webhook signing for [tests](/guides/testing) |
| `forges/schema` | [JSON Schemas](/reference/json-schemas) for the model types |
| `forges/kit` | Building blocks for [writing a provider](/contributing/write-a-provider) |

## Browsers

A browser never receives webhook deliveries, so the code that verifies and translates them would only add weight to your bundle. To avoid that, every provider except Pushin.eu comes with a second factory that leaves the webhook code out, such as `githubLite()` next to `github()`. If you are building for the browser, use the Lite factory. The [Browser bundles](/guides/bundling) guide has the details and the bundle sizes.
