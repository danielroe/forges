---
title: API explorer
description: Build a call to any operation on any forge, and run the reads against a real forge from the browser.
icon: i-lucide-play
---

The explorer writes the code for a call to any operation, on any forge. Pick an operation and a forge, then fill in the form or paste a link to a repository, issue or pull request. The code changes as you type, and you can copy it into your project.

Reads that a forge serves without credentials also run here, against the forge's public API. Your browser sends each request straight to the forge without credentials, so the forge's limits on anonymous requests apply. Tangled reads also go through public AT Protocol services, such as microcosm's Slingshot and Constellation. Writes and reads that need an account are code only, so copy the code and run it with your own credentials.

::api-explorer-page
::

Operations in the [API reference](/reference/overview) also have an explorer below their signature. To see which operations each forge supports, with and without credentials, see the [capability matrix](/reference/capability-matrix).
