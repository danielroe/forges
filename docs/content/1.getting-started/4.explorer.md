title: API explorer
description: Build a call to any operation on any forge, and run the reads against a real forge from the browser.
icon: i-lucide-play
---

The explorer writes the code for a call to any operation, on any forge. Pick an operation and a forge, then fill in the form or paste a link to a repository, issue or pull request. The code changes as you type, and you can copy it into your project.

Reads that a forge serves without credentials run here, against the forge's public API. Add a token, or a username and password, to run the reads and writes that need an account. Your browser sends the credential straight to the forge, over HTTPS, and never to forges.link: it stays in memory, or in this tab only while you keep **Remember in this tab** on. A write asks you to confirm the repository it changes first. Tangled reads also go through public AT Protocol services, such as microcosm's Slingshot and Constellation.

The credential form shows the fields your forge accepts and the scopes the call needs. If you don't have a credential yet, **How to create one** opens the [environment guide](/guides/environment#pick-the-variables-for-a-task) on the right forge and credential.

::api-explorer-page
::

Operations in the [API reference](/reference/overview) also have an explorer below their signature. To see which operations each forge supports, with and without credentials, see the [capability matrix](/reference/capability-matrix).
