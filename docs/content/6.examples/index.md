The [`examples`](https://github.com/danielroe/forges/tree/main/examples) folder holds projects that each solve one problem on any forge. Their tests run the real providers against fixtures, so you can read them as a guide to testing your own code.

::card-group
  ::card{title="Inbox CLI" icon="i-lucide-inbox" to="/examples/inbox-cli"}
  Print the notifications from every forge you configure.
  ::

  ::card{title="Label bot" icon="i-lucide-tag" to="/examples/label-bot"}
  Label new threads, and close them from a comment command.
  ::

  ::card{title="Release digest" icon="i-lucide-newspaper" to="/examples/release-digest"}
  Show the latest release and failing pull requests of any repositories.
  ::
::
